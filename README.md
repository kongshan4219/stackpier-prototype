# 栈桥交互原型

入口为 [index.html](index.html)。所有数据和操作均为浏览器内模拟，演示状态保存在当前站点的 localStorage；不连接真实服务器。

## 组件目录

| 路径 | 职责 |
| --- | --- |
| `assets/components/` | 工作台外壳、图标、公共控件和弹窗容器。 |
| `assets/features/` | 总览、服务器、部署配置、程序、巡检、设置等功能；各自维护页面、弹窗、按钮及表单处理。 |
| `assets/features/projects/` | 项目列表、详情、创建、配置与依赖关系。 |
| `assets/features/frp/` | FRP 数据、模型、文件生成、页面、弹窗、模拟操作及与工作台的衔接。 |
| `assets/features/operations/` | 操作记录界面、模拟执行与结果处理。 |
| `assets/features/network/` | DNS、防火墙及共用的网络模拟操作。 |
| `assets/core/` | 状态持久化、工具、导航、交互注册表、事件分发和加载失败提示。 |
| `assets/data/` | 虚构初始数据与试用场景。 |
| `assets/styles/` | 设计变量、基础与公共样式、响应式规则；FRP 专用样式放在对应功能目录。 |
| `assets/boot.js` | 全部组件就绪后的唯一初始化入口。 |
| `tests/` | 浏览器接口的内存替身与组件交互回归。 |

`index.html` 直接列出本地 CSS 和 JavaScript，不再拼接 `workspace.html` 与 `frp.js`。组件继续使用原生 JavaScript，按入口声明的依赖顺序加载，共用现有状态；不需要安装依赖或构建。

修改某项功能时，在对应功能文件中维护渲染和交互。公共弹窗容器只处理打开、关闭、焦点和布局；功能通过 `registerPrototypeHandlers` 注册自己的弹窗、按钮动作及表单处理。新增组件时同步维护入口加载顺序，避免重新聚合成大文件。现有 localStorage 键保持兼容，范围变化通过定向迁移处理。

## 预览与验证

在本目录通过仅监听回环地址的静态 HTTP 服务打开 `index.html`，例如：

```sh
python3 -m http.server 4311 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:4311/`，结束后停止自己启动的预览服务。

使用 Node.js 运行内存回归测试：

```sh
node --test tests/*.test.mjs
```
