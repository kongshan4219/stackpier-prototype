# Cloudflare 账号与 DNS 原型

仅浏览器前端和 localStorage 模拟，不调用 Cloudflare API，不创建真实账号或 Token，不修改真实 DNS。网络状态、检查与提交结果均为虚构演示。

## 统一入口与关系

“工作空间 / DNS 记录”的“管理 Cloudflare 账号”和“设置 / Cloudflare 账号”打开同一个管理界面，使用同一份 `S.cloudflare` 状态。关闭后保留来源页面和筛选；设置的未保存通知字段继续由现有表单缓存保留。

| 对象 | 身份与关系 |
| --- | --- |
| Account | 稳定 `id`；演示 Account ID 与显示名称另存 |
| 连接 | 稳定 `id`、accountId；每个 Account 只有一个未移除连接 |
| 凭据 | 独立 `id` 与 revision；只保存演示权限场景，不保存 Token 文本 |
| Zone | 稳定 `id`、accountId、显示域名 |
| DNS 记录 | 保留原记录 `id`，补充 accountId、zoneId，保留内容及 projects |
| 操作 | 固定连接、Account、Zone、记录、凭据引用及修订，不使用当前筛选作为目标 |

列表按账号筛选，Zone 选项来自实际状态并随账号联动。全部账号视图逐条显示账号与 Zone。只读、无权限、没有记录和已移除连接的缓存分别表达；已有记录的账号 / Zone 不可编辑。

## 接入、检查与更新

1. 填写名称，选择本次管理的演示 Account，使用“一键填入演示值”。同一个虚构凭据的多个可访问 Account 在选择器中明确列出。
2. 选择模拟授权情况，检查凭据有效性、Zone 读取、DNS 读取与逐 Zone DNS 修改能力。
3. 核对 Account 与授权域名，明确确认后保存连接。

提供正常、只读、失效、Zone 权限不足、DNS 权限不足、无授权域名、网络失败、范围缩小和分 Zone 授权场景。“检查成功”不等于全账号所有 Zone 均可读写。

Token 输入默认遮罩，更新时不回填旧原文，没有复制凭据入口。仅接受固定虚构值 `STACKPIER_DEMO_TOKEN_ONLY`；其他输入被拒绝并清空，不进入候选状态、localStorage、操作历史或修改意见导出。固定演示值本身也不持久化。禁止填写真实凭据，localStorage 不是生产密钥库。

重复 Account 接入引导更新已有连接。更新 Token 仍需先检查与确认；失败保留原连接。成功增加凭据修订，保留 Account、Zone、记录 ID 和项目关系。选择另一 Account 时引导新增连接，禁止改挂旧数据。范围缩小后保留原记录缓存，不宣称 DNS 被删除。

## DNS 操作与未知结果

保留 A、AAAA、CNAME、TXT、TTL、代理及多个关联项目。提交确认摘要包含目标账号 / Zone、凭据修订、记录内容和关联项目影响；共享条目需额外确认。

提交前重新检查目标身份、固定凭据修订和 Zone 写权限。异步结果只处理本次固定目标，切换筛选不会改变目标。账号连接与记录资源参与现有冲突保护；重复受理不排队或重放。

- 成功：模拟读取核对指定记录，标记“Cloudflare 已确认（模拟）”；公网传播仍未验证。
- 明确拒绝：保留原记录，不自动重试。
- 未知：保留输入、缓存及保护，通过只读核对原操作处理，不重新发送修改。
- 原执行已结束但历史结果无法证明：仅释放保护，保留未知，不伪造成功。

记录的本地确认修订用于阻止旧未知操作迟到核对覆盖后续已确认记录。项目卸载中选定的 DNS 清理也检查 Zone 权限并固定目标；旧清理缺少身份时保留记录，不能按名称猜测并删除。

移除连接只断开栈桥管理，不删除 Cloudflare 账号、域名或 DNS，也不代表撤销 Token。记录、项目关联与历史仍可核对。有执行中或未解除保护的未知操作时阻止移除与更换凭据。

## 兼容迁移

保持现有存储 key，不提升全局 version。移除“version 不等于 1 就恢复初始样例”的重置逻辑；有效旧对象继续执行增量迁移，服务器、项目、文件、部署配置和 FRP 保持原值。

旧 `settings.cfName` 迁移为旧版演示连接；原四条 DNS 示例及用户编辑保留，按旧单账号模型补齐记录归属。名称匹配只用于首次补齐缺失 Zone，后续使用稳定 ID。

增加第二个只读演示账号与虚构 TXT 示例；一次性标记防止重复添加。原 DNS 空数组保持空，迁移后的主动清空与连接移除不会在刷新时被示例填满。整体重置演示是独立的明确操作。

旧 DNS 操作及包含 DNS 清理的历史操作缺少可靠账号目标时标记“历史账号归属待核对”，保留原输入及历史，不猜测 Account。页面刷新使在途操作转为未知，保留其固定身份，不自动重跑。详情见[验证与截图](cloudflare-validation.md)。
