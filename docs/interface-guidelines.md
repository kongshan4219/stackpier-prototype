# 原型界面规则

路径说明：本页旧原型源码、脚本与测试已迁至 `legacy/radix-tailwind/`；相对命令在该目录执行，历史验收与证据身份保持不变。

当前本地原型采用 Radix Primitives + Tailwind CSS，[页面与接入规范](radix-redesign.md)是本轮审阅依据。正式 Web 保持已确认 Ant Design 基线。

## 文字与组件

- 颜色、文字和控件尺寸直接读取主仓库设计系统 tokens.json；设计系统公共组件和样式参与原型构建，产品布局位于 src/radix/styles.css。
- 正文 14px / 20px，辅助信息 12px，页面标题 24px / 32px。中文使用系统字体，不加载在线字体。
- 状态同时提供文字与语义颜色；链接、控件边界和焦点使用相应语义 Token。
- 操作区只突出主要动作；次要动作保持低强调。危险动作说明对象与影响，保留原确认流程。
- 列表先展示筛选与记录；历史证据折叠后仍有明确入口。详情使用定义列表与标签，不把每个字段都做成卡片。

## 响应式与键盘

- 桌面侧栏固定为 224px，820px 以下使用 Radix 导航抽屉，收起时不存在可聚焦的隐藏菜单。
- Escape 或关闭按钮退出抽屉并恢复触发器焦点；选择页面后进入标题。
- 页面负责纵向滚动；宽表只在表格容器横向滚动；配置、日志等必要长内容单独滚动。
- 模态标题和底部动作保持可见，正文滚动。Radix Dialog 负责背景隔离、焦点封闭与 Escape，不叠加原生 dialog。
- 搜索、按钮和输入框有可见焦点；提供“跳到页面内容”。窄屏主要操作和输入至少 44px。
- 支持浅色、深色与减少动态效果。浏览器自测范围与限制见[验证报告](radix-validation.md)。
