# 原型界面规则

原型沿用墨蓝与浅灰视觉体系，使用现有页面、样例与模拟流程持续审阅。正式业务开发等待用户明确确认原型满意后继续。

## 文字与组件

- 公共颜色、字号、控件尺寸与侧栏宽度在 `assets/styles/tokens.css` 维护。
- 基准正文为 16px，常用操作与表单文字为 14px，辅助信息为 12px；字号使用 rem，跟随浏览器字体设置。
- 次要文字使用统一的深灰蓝，状态仍通过文字与语义颜色共同表达。
- 按钮、表单、表格、标签、代码块和弹窗沿用公共组件；功能组件只补充该功能需要的布局。
- 操作按钮保持原有语义与确认流程，字号和排版整理不改变模拟业务结果。

## 响应式与键盘

- 桌面保持左侧导航与内容区；窄屏使用导航抽屉。
- 顶部审阅栏与抽屉共用高度变量，小屏审阅工具分两行展示。
- 收起的移动导航退出键盘焦点顺序；打开后焦点进入当前导航项，Tab 在抽屉中循环。
- Esc 或遮罩关闭抽屉后，焦点返回导航按钮；选择页面后，焦点进入页面标题。
- 搜索框提供可见焦点；键盘用户可通过“跳到页面内容”直接进入当前页面。
- 小屏主要操作与表单保持至少 44px 高，表格在自身容器内横向滚动。
