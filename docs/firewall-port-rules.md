# 防火墙端口规则原型

依据用户提供的 1Panel 端口规则截图，沿用栈桥导航与视觉，只调整主机防火墙页。不扩展端口转发、独立 IP 规则、禁 ping 或高级链控制。

- 页面先选择服务器，按主机入站展示协议、端口 / 范围、使用状态、策略、来源 IP、描述和操作；搜索、策略筛选、分页及勾选。监听未观测时不推测使用状态。
- 创建 / 编辑使用固定目标表单，支持 TCP / UDP / TCP+UDP、IPv4 / IPv6、所有或指定来源、允许 / 拒绝和描述。SSH 管理规则只读，拒绝规则不能覆盖管理端口。已有规则不要求栈桥归属。
- 编辑、删除先确认固定规则；导入版本 1 的 JSON，最多 50 项 / 256 KiB，先整体校验和预览。导出选中项，没有选择时导出当前筛选结果。批量操作保留一个固定服务器与整组差异，原规则变化则保持未知，不部分改写。
- 当前原型模拟 iptables，变更确认明确仅作用运行态；固定服务器 / 规则确认和运行态确认均为必选。检查详情说明实际工具、复杂规则和错误应如何展示，不模拟真实后端探测。
- 返回保留输入，取消不执行；模拟失败不改规则，响应未知保留原操作及核对入口。操作详情显示固定批量内容，不只显示内部 ID。

实现：`assets/features/network/firewall.js` 负责页面 / 编辑，`firewall-transfer.js` 负责导入导出 / 批量确认，`shared.js` 校验并应用模拟结果，`firewall.css` 负责局部样式。

组件测试 `firewall-ports.test.mjs` 覆盖主机入站筛选、管理保护、整体导入、固定目标、批量漂移和导入拒绝；完整 247 项组件测试通过。`browser-operation-context.py` 已同步当前正文部署表单及端口表单，56 项桌面 / 手机场景检查通过，包含导入错误、成功导入、选择导出和批量删除。截图保留于本任务缓存，不作为真实防火墙验收。

正式后端另按能力选择 UFW / firewalld / iptables / nftables，维护持久 / 运行态及独立恢复边界；本原型的模拟成功不证明目标执行、网络可达或用户验收。
