# 公共部署文件

“工作空间 / 文件”是程序、配置等公共部署资产库，不是源码编辑器或服务器目录浏览器。

## 逻辑文件与内容修订

同一逻辑文件的架构变体按稳定 `groupId` 归组；每个变体具有稳定 `fileId`（记录的 `id`），内容以 `revision` 固定。改逻辑名称不改变 ID，也不影响部署配置或项目引用。

文件详情抽屉展示逻辑名称、原文件名、保存文件名、类型、架构、大小、内容修订与 SHA-256。可选择历史修订；二进制只显示元数据，UTF-8 文本最多保存 64 KiB 供只读预览。大文件和二进制内容不写入 localStorage。

初始 catalog 程序是**模拟二进制元数据**，没有真实二进制或可验证 SHA-256，不表示程序已验证可执行。catalog-config.yaml 是虚构文本样例，其摘要对应样例文本。FRP 的四个 0 B 文件保持占位、不可部署。

列表中两个可点击计数分开计算：

- 引用配置数：公共配置当前修订引用这个逻辑文件的配置数。
- 使用项目数：仍在使用其当前或历史修订的已应用项目数，卸载项目不计为使用。

详情提供配置修订、映射目标与项目/服务器/已应用修订的反向入口。历史配置修订保留固定引用；旧文件修订不会因替换被删除。

## 上传、替换与命名

上传时读取用户选择的完整内容并计算 SHA-256；可识别的 ELF 记录架构，其他内容记录为通用。保存确认名称后才写入记录。相同 SHA-256 内容不能改名重复上传。

替换前展示受影响配置和已应用项目；替换产生新内容修订，保留原 ID 与历史修订。替换须保持适用架构。另一个架构通过上传新增，同逻辑名称归入原组。

公共配置固定修订与所有已应用/读取快照不因替换改变。公共配置编辑器可明确更新所选修订；项目也可在差异确认中采用文件新修订到独立草稿，随后仍需应用。

名称不允许路径分隔符、控制字符、`.`、`..`，UTF-8 长度不超过 255 字节；同适用范围名称不能冲突。修改逻辑名称会同步同组变体的显示名称。

文件分析上限为 256 MiB，超时 30 秒；需要 localhost 或 HTTPS Web Crypto。识别架构、计算摘要均不代表程序能运行。空文件可保存记录，但不能成为可部署映射或主程序。

分析、存储失败或迟到读取结果不会覆盖已有记录。浏览器原型不上传文件、不执行程序，不覆盖正式后端的存储、权限或并发实现。

参考：[ELF Header](https://gabi.xinuos.com/elf/02-eheader.html)、[Web Cryptography](https://www.w3.org/TR/webcrypto/)。
