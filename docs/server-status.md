# 服务器信息与状态

接入时模拟采集系统信息，随服务器记录保存在当前浏览器。正式应用将这些信息保存到 SQLite；原型不会连接 SSH 或访问真实数据库。

服务器页面每 30 秒更新一次模拟观测时间，保留登记时的系统信息和当前注入的成功、未知或指纹不匹配状态。离开页面或隐藏标签页后停止；返回后重新计时。“刷新状态”允许手动注入连接结果，不再次采集系统字段。

详情显示系统信息采集时间与最近状态检查时间。失败不能把旧系统信息清空，也不能因 SSH 不可达推断项目已停止。计时更新不产生操作历史记录。

页面组件见 `assets/features/servers.js`，页面装配在 `assets/components/shell.js` 里同步计时器生命周期。定时与离页行为由 `tests/server-status.test.mjs` 验证；正式数据库和真实输入交互在主仓库独立验证。
