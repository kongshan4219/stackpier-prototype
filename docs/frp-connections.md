# FRP 连接与部署

沿用“连接清单、代理与访问链路、TOML / unit 预览、部署与分项结果、模板与源码审阅”五个页面，复用工作空间文件、部署配置、项目及操作记录。全部为浏览器与 localStorage 模拟，不连接服务器。

## 参考模型与产品扩展

附件是一个本地 FRPC 提供端连接多个远端 FRPS。默认工作清单支持多台客户端机器，这是栈桥产品扩展。详情见[附件行为对照与验证](frp-reference-behavior.md)。

“载入附件参考示例”明确切换到独立参考清单，包含四节点、六 TCP、两 STCP、两个默认客户端目标与两组 visitor；工作连接、草稿和编辑缓存保留，可随时返回。两个清单是替代的模拟场景，不表示两套服务同时运行。公共程序资产共用，原有项目记录保留。

`client_enabled` 仅决定不指定客户端目标时默认选中；false 不禁用连接或服务。客户端 all 包含全部，显式指定 false 节点也可操作，服务端默认全部。批量页面可选单角色或三角色组合，按实际服务器角色去重 FRPS，客户端与 visitor 各自处理。

## 新增连接

先明确部署服务器上的 frpc / frps 角色，再选择对应服务器创建连接。frpc 部署准备程序，尚无连接时不生成或启动连接服务；frps 交付监听配置和 unit。失败、部分完成或未知不作为新的完整部署依据。

服务器选项依据完整应用参照，按主机去重；visitor、草稿、已卸载角色和只有程序名称的记录不作为已部署角色。已停止但完整安装仍在的角色可选择。保存时再次检查引用，拒绝失效选择、重复连接、同机映射名和监听冲突。已部署连接不能通过编辑隐式换机。

frps 监听地址和控制端口采用对应角色的配置。保存连接或代理只改变公共连接来源并提示更新；从详情采用到指定角色草稿，再单独确认模拟应用。卡片分别显示程序就绪、连接配置应用、角色运行及可用更新；运行不代表隧道或业务连通。

## 公共文件与版本

三种角色使用稳定 fileId、templateId、projectId 和固定内容修订。FRPS 使用 frps，FRPC 与 visitor 共用 frpc 的架构组，没有 visitor 二进制。文件详情列出当前公共配置引用、草稿角色、已应用项目与安装路径；历史模拟程序用未知内容身份的历史修订追溯，不假定使用了当前 0 B 文件。

部署配置详情区分引用的程序资产与生成的 TOML / unit，可查看历史保存正文、定位连接角色、查看项目或独立编辑公共配置。历史正文未保存时明确显示缺失，不使用最新正文冒充历史。原有 frpc · 内网连接、7400 和 frpc-edge 保留为历史自定义配置，不静默迁移或删除。

保存模板、全局设置、固定公共程序修订或替换文件，只产生新来源修订与更新提示。采用只修改指定角色项目草稿；完整应用参照、服务器读取结果和其他项目保持。公共配置固定所选程序修订，项目明确采用最新程序时形成自己的固定草稿引用。

连接、代理、模板和设置表单输入即时缓存。取消、打开文件抽屉、重复打开、切换页面与刷新保留未保存内容。来源跳转保留筛选及返回上下文。项目页分别展示只读读取快照、已应用参照、公共来源与项目草稿；读取失败保留上次成功内容及时间。

## 预览与模拟操作

执行前列出配置 / 设置 / 模板修订、匹配架构、内容身份、目标主机、生成路径、安装路径、unit、ExecStart 和依赖。附件 IP 命名、历史角色＋IP 命名及托管角色＋连接 ID / 服务器 ID 分开说明；根目录与用户是可配置示例。

四个附件程序均为 0 B，占位、缺架构、失效引用或不一致的 STCP / token 配对阻止部署；不存在勾选条件绕过空文件的开关。浏览器可保存真实上传元数据或明确的测试模拟元数据，但不保存大二进制，不验证可执行性。

结构校验不执行 FRP verify；生成不安装；安装登记文件与 unit 但不启动；部署明确交付并启动；停止保留 unit / 文件；卸载停止并移除 unit，保留共享程序和生成文件。删除最后一条 STCP 后，先采用到连接草稿，再在部署确认中列明 visitor 停止、unit、安装配置及生成文件的清理范围，明确确认才执行模拟清理。

批量逐目标保留成功、失败或未知，单项明确失败不隐藏后续结果。在途输入固定；迟到核对不覆盖新操作或抹掉此前成功项。共享 bin 替换提示其他服务，但不会自动重启它们。全局 token 或 STCP 变更必须核对实际配对的草稿与已应用版本，防止认证或密钥分叉。

概览和只读 TOML 默认遮挡示例凭据；localStorage 不是生产密钥库。所有运行、延迟、日志与执行结果仅代表原型模拟。
