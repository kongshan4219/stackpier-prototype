# 配置 / FRP

FRP 移到配置分组，仅管理已有服务的连接、TCP / STCP 映射、保存、预览差异、应用配置和结果核对。服务部署、启停、重启、完全卸载统一在工作空间 / 项目。旧 #frp 路由兼容，旧部署 / 审阅标签回到连接清单。

首页展示连接清单和选中连接映射；绑定、正文、修订、完整结果与公共模板放入详情。不再提供程序安装、架构上传、角色部署矩阵或服务卸载按钮。

## 服务关系

连接通过稳定 projectId 绑定已部署 FRPC、共享 FRPS 和可选 visitor，选择器显示服务器及服务运行观测。缺少服务显示“尚无可用服务”和项目部署入口。保存连接或映射不自动建立项目；只安装二进制不建立项目。

一个 FRPS 可供多个连接使用，执行计划按真实服务 ID 去重。单个 FRPC 服务不能隐式改接另一连接；visitor 采用独占绑定，一个 visitor 服务只允许一条连接。选择器显示占用并禁选，保存、应用及旧状态核对使用同一约束；共享 FRPS 不受此限制。已停止服务仍是已部署实例，应用配置保持停止；服务进程运行不代表隧道可达或业务健康，两页同用运行事实。

STCP 没有 remotePort；visitor 位于对应 FRPS 主机、使用 frpc、绑定回环。serverName / secretKey 来自同一映射。缺 visitor 可以保存配置但不能应用，不偷偷部署服务。

删除映射只改变配置。最后 STCP 删除时，应用预览说明清空 visitor 映射，保留其服务 / unit；完全卸载另到项目确认。删除连接也先标记配置删除、再应用空配置，不卸载任何服务或删除共享 FRPS。

已应用连接改绑采用两步确认：先「改绑前解除旧配置」，列明旧客户端 / visitor 映射清空及重载，旧 FRPS 仅核对并保留。全部成功后才能保存新绑定，再单独确认新服务应用。任何旧角色离线、失败 / 部分 / 未知均保留原应用绑定、占用和恢复入口，不卸载服务。旧应用绑定缺证据、visitor 冲突保守阻断，不静默解绑。

## 保存、采用与应用

保存连接 / 映射仅更新配置修订与待应用标记。保存公共模板、全局设置或替换文件仅产生可用更新；采用只修改指定连接 / 服务草稿，不改变已应用 / 读取参照或其他草稿。

应用确认列明固定配置修订、服务和文件、共享影响、必要重载 / 重启。只有模拟成功且读取核对完整才更新应用参照。失败、部分写入或未知保留旧完整参照，逐服务结果保留；未知先核对原操作，不盲目重提。

共享 FRPS 的 token 改动必须相关连接分别明确采用同一认证，然后计划同时列出其客户端和 visitor；FRPS 仅一次。单项目认证 / 映射应用会引导到配置 / FRP 协调，不让单服务破坏配对。

连接、映射、模板和设置编辑取消 / 重开 / 刷新保留草稿；跨文件、配置、连接、项目定位保留来源筛选。只读读取失败保留上次成功内容与时间并标旧。

## 公共资产、参考与路径

FRPS 使用 frps，FRPC / visitor 使用 frpc；稳定 fileId / templateId / projectId 与固定修订，反向列出配置、已应用服务、版本和路径。生成 TOML / unit 与上传程序分开，没有伪造生成文件资产。四个附件程序仍为 0 B，不可部署；模拟 QA 元数据不证明二进制可执行。

附件模型是一个本地 FRPC 连接多个远端 FRPS，默认多客户端是产品扩展。参考清单四节点、六 TCP、两 STCP、两个默认目标、两 visitor，显式载入不覆盖工作连接。client_enabled 仅控制默认目标，false 不代表禁用；all 与指定仍包含该节点。参考清单不会生成项目。

附件生成路径 generated/frpc、frps、frpc-visitor 下 IP.toml / IP.service；安装 unit 客户端 / FRPS 为 IP.service、visitor 为 IP-visitor.service。新托管服务以项目名命名 unit，配置在可配置运行根目录 / projects / 项目名；共享 bin/frpc、bin/frps。旧角色＋连接 ID / 服务器 ID 服务保持原落点，不冒充附件命名。

历史 frpc · 内网连接、7400 与 frpc-edge 继续作为历史自定义服务 / 配置保留，不混作新三角色连接。概览遮挡示例凭据，localStorage 不是生产密钥库。

行为对照见[附件说明](frp-reference-behavior.md)，当前生命周期验收见[项目与 FRP 验证](service-lifecycle-validation.md)，五项缺陷修复与截图见[专项回归](cleanup-frp-repairs.md)。仅前端与本地模拟，没有真实 SSH、FRP、服务器或端口验证。
