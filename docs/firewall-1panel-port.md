# 1Panel 防火墙四模块审阅原型

本原型基于 1Panel v2.4.0 / `04099ae2a26953aa8fffef3d8a1def590ebf33e4` 的实际源码。四模块范围已经确认纳入；D1、D2 已确认跟随 1Panel 探测、显式选择、固定 public、自有链与初始化；D3 写入保护亦确认完全跟随上游；D4 导入格式/限额/批次语义亦完全跟随上游，不兼容旧 stackpier-port-rules 格式；D5 重置与联动亦完全跟随上游清理范围、默认值、确认流程及处理顺序；D6 已确认新操作完全跟随 1Panel、旧记录仅保留查询，后续手动清理；完整原型已获用户确认，可以进入正式移植。

## 入口与使用

构建与启动沿用 [README](../README.md#预览与验证)，本次页面入口为 `/?firewall=1panel#firewall`；普通 `/#firewall` 保持已确认旧原型。可指定 `STACKPIER_PROTOTYPE_VITE_CACHE` 隔离本任务 Vite 缓存。

页面继承 StackPier 外壳、Ant Design 深浅主题和服务器选择，内容按上游系统防火墙、Docker 端口防护、端口转发、设置组织。这里的任务、备份、权限、服务器与命令结果全部是浏览器模拟，不访问任何 API。新审阅数据在当前 React 会话内保存，刷新页面、切换外壳主题或重新进入会重置；没有写入原有防火墙样例存储。

建议审阅顺序：

1. 系统防火墙：创建来源/端口多行输入、TCP/UDP 组合、错误校验、编辑优先级和描述、受保护/复杂规则、批量选择、JSON 导入预览/导出。
2. Docker：容器分组 → 详情 → 选择发布端点 → 设置策略；孤立策略保留说明。混合地址族只可一起设全部拒绝，按来源规则须分开。
3. 转发：地址族、源端口、目标 IP/端口、入站网卡；空目标为对应族回环。编辑保留旧项身份，提交确认后模拟替换。
4. 设置：三类子系统独立后端、IPv6、禁 Ping、白名单。主页面演示服务型启停/重启和直接后端初始化/绑定/解绑/修复；重置默认备份，可从备份初始化。
5. 展开“原型审阅工具”，检查无权限、未安装、停止、双栈失败、冲突等状态；下次结果可设失败/部分成功/未知。未知结果保留原任务和核对入口，不自动重发。
6. 查看“适配裁决记录”：D1 管理器识别与 D2 作用范围/自有链/初始化已确认跟随上游，D3 写入保护已确认完全跟随上游，D4 导入/批次亦已确认完全跟随上游，D5 重置与联动亦已确认完全跟随上游，D6 已确认旧记录只读、不续执行或恢复，后续手动清理。

## 来源与实现边界

[来源与 GPL](third-party/1panel/README.md)；`src/antd/firewall-port/validation.ts` 是上游纯校验文件原样复制。`copy.js` 集中文案，`model.js` 仅模拟模型及输入处理，`page.jsx` 组织状态与四页，`dialogs.jsx` 维护表单/导入/确认，`docker.jsx` 维护容器端口详情。

迁移上游 Vue 交互到 React，未复用上游 API 服务或启动 agent。原型采用虚构观察演示 raw/opaque、保护项、状态/权限和任务结果；**没有移植 Go 四后端解析、命令编译、持久化或真实恢复**。浏览器数组替换不代表真实 remove/add 的顺序和补偿已经实现，重置备份也不代表目标侧文件已保存。

本审阅稿不验证上游任意原始规则导入、所有 nativeKind 的命令语义、真实 Docker 拓扑与版本限制、RA 修复、Fail2Ban 联动、自动网站放行或重启恢复。它们仍在主仓库完整映射内，不因原型模拟简化而从移植范围删除。正式移植须使用固定上游代码补齐对应测试；不能复用本原型的简化模型充当生产解析器。

D1–D6 面板是审阅工具，不进入正式产品。上游固定 public、自有链、异步任务与当前 StackPier 的差异均保留标识；D2 已明确取消多 Zone 扩展；D3 已取消新操作的旧固定预览、120 秒恢复、新 SSH 确认及额外防误封门槛，保留上游自身保护；D6 已确认旧回执只保留查询及原始状态，不自动重放、恢复或删除。
