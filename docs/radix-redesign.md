# Radix 原型重做

旧原型现位于 `legacy/radix-tailwind/`；下文源码相对路径与命令均以该目录为工作目录，依赖使用其中的独立 package.json 和锁文件。历史检查结果与截图身份不变。

2026-11-03 本地审阅稿。采用主仓库「应用设计系统」的 Radix Primitives + Tailwind CSS。用户要求先重做原型，正式 Web 保持 Ant Design；本稿尚未获视觉确认，也未推送或发布。

## 页面规范

- 工作台：224px 桌面侧栏、紧凑审阅工具菜单、单层路径。820px 以下使用 Radix 导航抽屉，选页后焦点进入标题。
- 项目：标题与部署动作 → 分类 → 可展开的未完成操作摘要 → 搜索筛选 → 项目记录。恢复入口与历史证据仍可展开查看。手机记录保留名称、服务器、状态、问题与管理动作。
- 详情：对象身份、动作和紧凑状态摘要在前，Radix Tabs 切换概览、配置、巡检、日志和记录。固定部署信息与草稿入口保持原有行为。
- 部署：运行方式采用左对齐选择卡，再填写目标服务器、名称和已保存配置。校验、固定预览和单独确认执行保持原有流程。
- 部署配置：卡片使用短定义行展示映射与项目引用；编辑器固定标题和操作栏，仅正文滚动。systemd / Compose / FRP 字段与保存行为保持原有模型。
- 服务器、文件、FRP、巡检、DNS、普通防火墙、操作记录和设置：统一标题、筛选、卡片、表格、表单与反馈，移除强制等高和多余的嵌套纵向滚动。宽表在自身容器横向滚动。
- 1Panel 防火墙独立审阅入口继续保留，四模块使用原有 React 模拟模型，控件改为 Radix 与原生表单组合。仍不代表真实执行。

正文为设计系统的 14px / 20px 基线，辅助信息 12px；页面标题 24px / 32px。桌面控件 36px，手机主要控件 44px。语义色与深浅主题从同一 Token 来源编译。总览磁盘示例采用单一 blue9 用量条、同色阶轨道、可见百分比与可聚焦提示，不把用量颜色当成健康状态。

## 实现边界

| 路径 | 职责 |
| --- | --- |
| src/radix/shell.jsx | 工作台、导航、主题与原型状态审阅 |
| src/radix/projects.jsx | React 项目列表与详情框架 |
| src/radix/index.jsx | React 根、Radix Dialog / Toast 生命周期 |
| src/radix/controls.jsx | 防火墙所需的 Dialog、Tabs、Checkbox、Switch、表单与表格组合 |
| src/radix/firewall-port/ | 四模块防火墙原有模拟模型、校验与页面 |
| src/radix/fragments.jsx | 已转义领域 HTML 的显示边界 |
| assets/core/radix-bridge.js | 状态快照、动作与原生表单事件桥接 |
| src/radix/styles.css | 页面组合和原生业务控件样式，直接消费设计系统样式 |
| scripts/build-radix.mjs | 从 Token、公共 React 组件与 Tailwind 输入构建离线预览 |

本轮移除了 Ant Design 依赖、转换器和原有基础样式。工作台、项目框架与防火墙使用 React；其余领域视图及复杂表单继续复用已转义 HTML 和原生控件，由 React 宿主显示，业务模型没有重写。没有将所有业务视图改写成 JSX，也没有用字符串解析器替换其控件。这一边界让现有草稿、固定目标、文件引用和恢复逻辑继续使用同一处理器。

数据仍存于当前站点 localStorage，主题沿用原存储键。页面状态审阅的空、加载、失败只是显示场景，不删除原数据。配置正文、凭据和文件内容不写入 URL；历史导航沿用既有白名单路由。
